# ThingsBoard 设备遥测与检修协同 MVP 报价单

报价日期：2026-11-02

报价性质：课程演示 / 虚拟项目 / 本地部署版

## 1. 报价方式

采用：

```text
项目开发固定总价/整包
+ 功能点与规模明细
+ 云资源单列
+ 大模型 Token 单列并设置封顶
```

AI 功能按“半人工开发”计价，不按纯算法研发溢价。模型调用、知识整理和提示词调试
计入项目开发，正式运行产生的 Token 费用按实际用量单列。

## 4. 交付内容

- ThingsBoard 接入适配器和本地演示数据。
- FastAPI 后端、SQLite 本地数据库。
- React / Vite 前端。
- LangGraph + RAG + 知识图谱。
- 42 条公开知识记录及来源链接。
- 自动化测试。
- 示例数据和 ThingsBoard 告警推送脚本。
- `docs/` 中的设计方案、流程图、API 说明和报价单。
- 本地启动说明和演示脚本。

## 5. 不包含

- 真实工厂设备接入和现场网络施工。
- 正式 CMMS/EAM 商业系统对接。
- 设备停机、启动、复机和上锁挂牌控制。
- 公共服务器、域名、HTTPS 和长期运维。
- 真实生产数据的清洗、标注和合规评估。

## 7. 报价假设

1. 项目按本地单机演示交付。
2. ThingsBoard 使用本地 Docker 社区版。
3. 大模型通过百炼 OpenAI 兼容接口调用。
4. AI 为只读辅助，不承担设备控制和生产恢复责任。
5. 需求冻结后新增功能单独报价。
6. 本报价为课程与虚拟项目参考，不包含税费和长期 SLA。
