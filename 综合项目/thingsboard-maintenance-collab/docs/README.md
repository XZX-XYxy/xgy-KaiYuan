# 文档索引

本目录保存课程提交所需的调研、设计、流程图、报价与演示材料。

## 调研与方案

- `business-discovery.md`：现场业务需求发现报告。
- `industry-and-competitors.md`：行业现状、GitHub 类似方案与无 AI 流程图调研。
- `industry-and-competitors.docx`：行业调研 DOCX 提交件。
- `industry-and-competitors.pdf`：行业调研 PDF 提交件。
- `ai-design.md`：AI 增强版设计方案。
- `ai-design.docx`：AI 增强版设计方案 DOCX 提交件。
- `ai-design.pdf`：AI 增强版设计方案 PDF 提交件。
- `design.md`：系统设计摘要。
- `api.md`：API 约定。
- `thingsboard-integration.md`：ThingsBoard 接入说明。

## 图表与交付材料

- `flowcharts/`：无 AI 与有 AI 系统流程图的 PNG、SVG 文件。
- `quote/`：报价单，包含 Markdown、DOCX 和 PDF。
- `knowledge-graph/`：知识图谱说明与桌面、手机截图。
- `screens/`：总览、告警、工单和知识问答页面截图。
- `presentation/index.html`：可直接打开的 5 分钟汇报页面。
- `presentation/assets/`：汇报页面引用的图片资源。
