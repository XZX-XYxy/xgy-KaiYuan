02 CAPABILITIES

能力不是清单，
是交付链路上的证据。

从需求发现到界面实现，再到测试与开源材料整理。下面的每项能力，都能在项目里找到对应的产物。

数据与 AI

做只读 AI 辅助、RAG 检索、候选归并与输出校验，把不确定性留在流程里。

  • LangGraph / RAG
  • Pandas / SQL 基础

产品与界面

把功能组织成可扫描的界面，同时考虑桌面端、移动端与空状态。

  • ScanCode Toolkit

D

验证与交付

不只证明“能打开”，还用自动化检查与测试记录说明哪里可用、哪里仍有边界。

  • Playwright 布局审计
  • Pytest / Hypium
  • 技术文档与汇报

MY WORKING LOOP

  1. 01
    看清约束

    先找真实角色、失败案例和不能跨越的边界。

  2. 02
    做出原型

    用最小可运行版本验证数据、交互与异常路径。

  3. 03
    留下证据

    用测试、截图、扫描结果和文档完成交付闭环。

一个学期，
五次递进。

对照“开源微专业（周四）”课程材料与 GitHub 提交记录，从网页基础走到完整的产业场景 MVP。

  1. 09.17
    网页基础

    个人主页与发布流程

    练习响应式布局、交互脚本与静态站点发布，开始形成自己的公开表达。

  2. 09.24
    鸿蒙入门

    ArkTS 校园提醒原型

    用声明式 UI、状态管理和列表渲染搭出校园提醒卡片。

  3. 10.08
    智能体实验

    画风萃取与提示词工坊

    完成零依赖视觉创作助手，用真实像素分析与本地存储验证产品设想。

  4. 10.15
    应用上架

    HarmonyOS 工程与发布准备

    补齐应用配置、测试结构和上架实操理解，把原型推进到可交付工程。

  5. 10.29
    综合项目

    ThingsBoard 检修协同 MVP

    完成调研、设计、开发、测试、报价与汇报材料，形成一套可运行的产业场景方案。
