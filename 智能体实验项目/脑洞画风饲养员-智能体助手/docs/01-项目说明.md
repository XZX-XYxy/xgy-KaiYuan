## 2. 背景

AI 绘图已经进入日常办公与文化场景，活动配图、宣传小海报、文化素材、团队趣味物料都存在轻量创作需求。但通用绘图工具有三个现实门槛：

1. **提示词门槛高**：普通用户不知道该描述媒介、光线、色彩还是构图。
2. **效果不稳定**：同一句话多次生成，风格漂移明显。
3. **风格难统一**：一套物料需要反复调试，才能勉强保持同一种视觉语言。

结果是，用户要么放弃自己创作，要么把需求转交给设计岗位，轻量创意被流程成本消耗掉。

## 3. 问题定义

本项目要解决的不是「如何生成一张图」，而是更靠前的一步：

> 如何让不懂提示词的普通用户，把自己喜欢的一套视觉参考，变成一份可重复调用的画风资产？

把这个问题拆开，需要同时满足三件事：能从参考图里读出风格、能把风格存成结构化档案、能把档案重新组装成可用的提示词。

## 4. 目标用户

| 用户类型 | 典型诉求 | 当前障碍 |
| --- | --- | --- |
| 无设计基础的普通员工 | 做团建配图、活动海报、部门简报插图 | 不会写提示词，生成结果不可控 |
| 有审美但不懂技术的创意爱好者 | 探索个人风格、做兴趣创作 | 每次都要重新描述风格，无法沉淀 |
| 小范围共创的同事群体 | 共享一套视觉语言做系列物料 | 风格靠口头描述，难以复现 |

## 5. 产品定位

「脑洞 & 画风饲养员」定位为**轻量 AI 视觉创作助手**，不做通用绘图平台，也不做专业设计软件。它只负责三件事：

- **萃取**：从参考图提取可解释的视觉特征。
- **沉淀**：把特征整理为个人私有的画风档案。
- **复用**：把画风档案组装为成片提示词，交给任意绘图工具执行。

## 6. 目标与价值

1. **降低门槛**：用户只需要上传图片、点选几个描述词，不需要理解提示词工程。
2. **稳定风格**：同一份画风档案可以反复调用，减少随机漂移。
3. **沉淀资产**：画风属于用户个人，可导出、可分享、可迁移。
4. **活跃文化**：把 AI 创作从「一次性的玩具」变成可积累的个人资产。

## 7. 范围边界

本期明确不做以下内容，避免把概念说得比实现更大：

| 不做 | 原因 |
| --- | --- |
| 直接生成图片 | 需要接入第三方绘图 API，涉及费用、密钥与内容安全，不在本期范围 |
| 训练或微调风格模型 | 本期采用可解释的像素统计 + 结构化提示词，不宣称拥有生成模型 |
| 账号体系与云端同步 | 本期以本地优先为原则，资产保存在浏览器 `localStorage` |
| 多人实时协作 | 分享以文本卡片形式完成，不构建协作后端 |
| 版权素材库 | 参考图由用户自行提供，工具不内置图库 |

## 8. 与推荐表的一致性

推荐表中提出的四个能力，在本期实现中的对应关系如下：

| 推荐表表述 | 本期实现 | 说明 |
| --- | --- | --- |
| 数字化风格萃取 | 72×72 采样 + 5 类 k-means 主色板 + 明度/饱和/冷暖/反差统计 | 真实计算，不是预设文案 |
| 多套画风饲养沉淀 | 画风库，支持保存、应用、删除、导出 JSON | 存于 `localStorage`，单机可用 |
| 简易文字描述生成多尺寸图像 | 作品工坊，5 种画幅比例 + 用途选择 + 提示词组装 | 产出提示词与预览画布，不直接出图 |
| 自愿分享、小范围共创 | 分享卡片复制、画风资产包导出 | 不涉及服务端 |

## 9. 术语

- **画风档案**：一份包含命名、色板、光影、色调、氛围、关键词与成片提示词的结构化记录。
- **萃取**：从参考图像素中计算视觉特征的过程。
- **成片提示词**：按固定结构组装、可直接粘贴到绘图工具的一段文字。
- **画风资产**：保存在画风库中的一条画风档案。
