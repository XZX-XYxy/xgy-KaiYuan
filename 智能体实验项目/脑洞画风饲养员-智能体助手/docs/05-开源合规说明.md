# 开源合规说明

## 1. 本项目许可证

本项目代码采用 **MIT License**，全文见仓库根目录 `LICENSE`。

MIT 允许他人自由使用、复制、修改、合并、发布、分发、再许可和销售，只需保留版权声明与许可声明。选择 MIT 的原因：

- 课程作业需要清晰展示开源许可实践；
- 项目为单文件前端工具，MIT 与使用场景匹配；
- 便于后续同学复现与二次开发。

## 2. 第三方组件

| 组件 | 用途 | 许可证 | 分发形式 |
| --- | --- | --- | --- |
| Lucide 图标路径 | 界面线性图标 | ISC | 以内联 SVG `path` 数据形式嵌入 `index.html` |

Lucide 的完整许可证文本已收录在 `third-party/NOTICE.md`。嵌入时保留了原始路径数据，未修改图标语义。

## 3. 无第三方运行时依赖

项目不包含 `package.json`、`node_modules`、Python 包或其他运行时依赖，也不在运行时请求任何远程资源。因此不存在需要随产品分发的依赖许可证清单。

## 4. 字体

界面使用系统字体栈：

```
-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB",
"Microsoft YaHei", "Segoe UI", system-ui, sans-serif
```

不下载、不打包、不分发任何字体文件，因此不涉及字体授权问题。

## 5. 图片与素材

- 应用内不内置任何第三方图片素材。
- 画风库封面与工坊预览由 Canvas 按色板程序生成。
- 用户上传的参考图仅在本地浏览器内处理，不上传到任何服务器。
- 仓库中的界面截图由本项目实际运行生成。

## 6. 数据与隐私

| 数据 | 存放位置 | 是否上传 |
| --- | --- | --- |
| 参考图 | 浏览器内存 + `localStorage` 缩略图 | 否 |
| 画风档案 | 浏览器 `localStorage` | 否 |
| 用户输入文本 | 浏览器内存 | 否 |

项目没有后端、没有埋点、没有第三方统计脚本。

## 7. 未纳入仓库的材料

以下材料**没有**放入本仓库：

- 原始参赛推荐表 DOCX：其中包含团队成员手机号与邮箱，不适合公开分发。
- 团队内部沟通记录与未脱敏截图。

如需在课程材料中引用推荐表内容，应使用脱敏版本。

## 8. 课程报告中的个人信息

`report/大数据250164-f25016436-徐郭源-作业2.docx` 的封面按课程模板包含姓名、班级、学号。若仓库设为公开，请确认这些信息是否适合公开；也可以将仓库设为私有后邀请教师查看。

## 9. 合规结论

- 代码许可证清晰（MIT）。
- 唯一第三方代码（Lucide 图标路径）已按 ISC 要求保留声明。
- 无运行时依赖、无远程资源、无字体分发。
- 用户数据本地处理，不上传。
- 未发现许可证冲突或需要额外披露的组件。
