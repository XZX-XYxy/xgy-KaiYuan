# 产品设计

## 1. 设计原则

1. **先看结果，再谈参数**：用户先看到色板和档案，再决定是否保存，不要求先理解算法。
2. **每一步都有可见反馈**：上传有缩略图、萃取有进度态、保存有轻提示、复制有确认。
3. **资产归用户**：默认私有、本地保存、可导出，不设置任何上传或注册门槛。
4. **不夸大能力**：界面只承诺「生成提示词与预览」，不暗示自己完成了图像生成。

## 2. 信息架构

应用由四个并列工作台组成，左侧为固定导航（移动端转为顶部横向标签栏）：

```
饲养画风  →  萃取并生成画风档案
脑洞孵化  →  把灵感扩写为画面脚本
画风库    →  管理已保存的画风资产
作品工坊  →  组合画风与主体，产出成片提示词
```

四个工作台共享同一份画风数据，形成一条单向可回流的链路：

```
参考图 → 画风档案 → 画风库 → 作品工坊 → 成片提示词
              ↑                    ↓
              └──── 脑洞脚本 ←──────┘
```

## 3. 模块设计

### 3.1 饲养画风

**输入**：最多 8 张参考图、画风名称、质感标签（多选）、氛围标签（多选）。

**过程**：点击「开始萃取」后，按钮进入禁用态并显示进行中文案，避免重复提交。

**输出**：5 色主色板、风格范式、光影关系、色调质感、场景氛围、采样统计、关键词、成片提示词。

**后续动作**：保存到画风库 / 复制提示词 / 去工坊。

**边界**：参考图少于 1 张时提示先上传；读取失败时给出失败提示，不产生空档案。

### 3.2 脑洞孵化

**输入**：一句灵感、情绪基调（多选）、变体数量（3 或 5）。

**过程**：基于输入文本的哈希值做确定性抽样，从场景、动作、情绪、构图、光线五个池中各取不重复项。

**输出**：每个变体包含主体、场景、动作情绪、构图、光线与一段完整提示词。

**后续动作**：复制脚本 / 送去工坊（自动填充画面主体）。

### 3.3 画风库

**展示**：画布封面、名称、色块、标签、操作按钮。

**操作**：应用（跳转工坊并选中）、复制提示词、生成分享卡片、删除。

**批量操作**：导出全部为 JSON、清空。

**空态**：提供「载入预置画风」，让首次使用者不必先上传图片也能完整体验。

### 3.4 作品工坊

**输入**：画风模板、画面主体、画面比例（1:1 / 4:3 / 3:4 / 16:9 / 9:16）、使用用途。

**输出**：按当前画风色板绘制的预览画布、结构化成片提示词。

**交互**：切换画风或比例会即时重绘；「刷新预览」会推进随机种子，生成同色系的新构图。

## 4. 关键流程

### 流程 A：从参考图到画风资产

1. 上传 3～8 张同风格图片。
2. 填写名称，选择质感与氛围。
3. 点击萃取，查看色板与四项描述。
4. 保存到画风库。
5. 刷新页面后仍可在画风库找到该资产。

### 流程 B：从灵感到成片提示词

1. 在脑洞孵化输入一句灵感。
2. 选择一个或多个情绪基调。
3. 生成 3 或 5 个变体。
4. 选择满意的变体，送去工坊。
5. 在工坊选择画风、比例、用途，生成并复制提示词。

## 5. 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 空态 | 虚线框 + 单句说明 + 下一步动作 |
| 加载态 | 主按钮禁用，文案改为「正在萃取…」 |
| 成功态 | 底部轻提示 1.9 秒后自动消失 |
| 异常态 | 提示「图片读取失败，换几张试试」，保留已上传文件 |
| 危险操作 | 删除、清空使用弱化的幽灵按钮，悬停才显红色 |

## 7. 视觉规范

| 项目 | 规则 |
| --- | --- |
| 主色 | `#00A96E`（元气绿），用于主按钮、选中态、强调图标 |
| 中性色 | 背景 `#EFF1EF`，卡片 `#FFFFFF`，正文 `#101312`，辅助文字 `#6E7772` |
| 圆角 | 卡片与按钮统一 8px，标签 6px |
| 字体 | 系统中文字体栈（苹方 / 微软雅黑），不下载外部字体 |
| 图标 | Lucide 线性图标，1.8px 描边 |
| 间距 | 4px 基准，卡片内边距 18px，模块间距 14px |

## 8. 可访问性

- 所有图标按钮均带 `aria-label` 或可见文字。
- 选中态使用 `aria-pressed` / `aria-current`，不只依赖颜色。
- 键盘支持 `Esc` 关闭弹窗，`Ctrl/Cmd + Enter` 触发萃取或孵化。
- 正文与背景对比度满足常规阅读需求。
